# auris

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

**auris**（ラテン語で「耳」）は、音声を検索・共有可能なテキストに変換するオープンソースの音声文字起こしワークベンチです。ファイルアップロード、直リンク、Bilibili 動画、小宇宙（Xiaoyuzhou）ポッドキャストなど多彩な入力ソースから、プラグイン式の ASR エンジンによる文字起こし、アプリ内通知の配信まで、エンドツーエンドのパイプラインを提供します。

## 主な特徴

- 🎙️ **プラグイン式 ASR エンジン** — Whisper、Qwen3-ASR、ストリーミング音声の 3 プロバイダーを内蔵。VAD による賢いセグメンテーションで、長短両方の音声に対応
- 🔗 **マルチソース入力** — ファイルアップロードは同期的に結果を返却。URL は非同期タスクで処理し、Bilibili 動画・小宇宙ポッドキャスト・直リンク音声を自動取得
- ⚡ **ストリーミング文字起こし** — WebSocket によるリアルタイム認識、話しながら結果が出力
- 🧱 **マイクロサービスバックエンド** — Spring Boot 3：gateway（ルーティング）/ user（JWT 認証）/ ai（文字起こしオーケストレーション）/ push（通知配信）
- 📨 **イベントドリブン通知** — 2 階層 Kafka トピック構成。アプリ内 / メール / Feishu のマルチチャネル配信に、2 階層の冪等性、DB 駆動リトライ、DLQ（デッドレターキュー）を実装
- 🖥️ **モダンな Web フロントエンド** — Vue 3 + TypeScript + Tailwind CSS で、文字起こし・履歴・通知・プロフィールをワンストップで

## アーキテクチャ概要

| モジュール | 技術スタック | 担当 |
|---|---|---|
| `engine/` | Python · FastAPI | AI エンジン：ASR（同期 / 非同期 / ストリーミング）、VAD セグメンテーション、長時間音声タスク、マルチソース取得 |
| `server/` | Java · Spring Boot 3 | 業務マイクロサービス：gateway ルーティング、user 認証、ai オーケストレーション、push 通知、共通ライブラリ |
| `frontend/` | Vue 3 · TypeScript · Tailwind CSS | Web アプリ：文字起こしワークベンチ、履歴、アプリ内通知、プロフィール |
| インフラ | MySQL · Redis · Kafka · Nacos | 永続化、キャッシュ、イベントストリーム、サービスレジストリと設定 |
